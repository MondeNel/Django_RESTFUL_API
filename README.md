# Django_RESTFUL_API

A simple RESTful API built using Django and Django REST Framework that allows you to **Create**, **Read**, **Update**, and **Delete** blog posts (CRUD operations).

## 🚀 Features

- Create blog posts
- Retrieve a list of blog posts
- Update existing blog posts
- Delete blog posts
- RESTful endpoints using Django REST Framework

## 🛠 Technologies Used

- Python
- Django
- Django REST Framework
- Environs (for environment variables)
